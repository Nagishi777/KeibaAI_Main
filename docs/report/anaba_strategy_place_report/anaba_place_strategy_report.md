## 0. 要点

| 問い | 答え |
|---|---|
| 回収率はどう変わる？ | **136.98% → 122.67%。14ポイント下がる**（§2） |
| では複勝は劣るのか？ | **一概に劣らない。** CI下側は 111.9% → 112.1% でほぼ同じ。**最大DDは1/3、連続不的中は1/4になる**（§2・§6） |
| 単勝版の最大の弱点は直るか？ | **直る。** 単勝は上位15配当を失うと赤字だが、**複勝は上位38点まで100%超**（§4） |
| 歪みは本物か？ | **本物。** ラベルシャッフル300回で控除率どおり77.5%に戻り、p < 0.0033（§5） |
| 複勝が勝つ帯は？ | **15〜50倍。** 単勝と逆で、**80倍超では複勝が崩れる**（108%）（§5.1） |
| もっと良くできる？ | **できる。** 複勝専用モデルで 138.79%・CI下側118.6%（単勝を上回る）。ただし事後的な条件選択（§7） |
| どちらを採るべき？ | **資金30万円未満・短期で手応えが要るなら複勝。** 資金が厚く分散に耐えられるなら単勝（§8） |

> **IMPORTANT: 「回収率が下がる＝劣る」ではない**
> 複勝が落とすのは**点推定だけ**である。信頼区間の下側（＝計画の土台にすべき値）は
> 単勝 111.9% に対し複勝 112.1% で、実質的に同じ。
> 単勝版 §9 が「点推定137%を期待値として信じるのは危険で、下側の109%を基準に
> 考えるべき」と述べている以上、**その基準で見れば両者は互角であり、
> 複勝のほうが遥かに低リスクでそれを達成する。**

## 1. 検証条件

### 1.1 単勝版と揃えたこと

比較が券種の差だけになるよう、**データ・分割・学習条件は単勝版と完全に同一**にした。

| 条件 | 内容 |
|---|---|
| データセット | `dataset.py` の出力（165,714行 / 11,931レース） |
| OOS | 115,841行 / 8,340レース（2024-01-06〜2026-07-26） |
| ウォークフォワード | 四半期ごと11フォールド。各フォールドは開始日より前のデータだけで学習 |
| ホールドアウト | 学習期間末尾20%。early stopping と isotonic 校正に使う |
| シード | 5本独立再学習してアンサンブル |
| 特徴量 | 29列（単勝版と同一。市場スナップショット + レース属性のみ） |
| **決済** | **確定払戻**（`payout_place`）。1m のオッズで貰えたとは仮定しない |

**リーク防止**: 入力29列はすべて締切前の市場スナップショットとレース属性である。
着順・確定オッズ・確定人気・払戻は特徴量に含まれていない。

### 1.2 複勝固有の扱い（ここが単勝版と違う唯一の点）

> **IMPORTANT: 複勝オッズは締切前には「範囲」でしか分からない**
> 複勝の配当は**どの馬が一緒に入着したか**で変わる。したがって締切前に
> 確定するのは min〜max の幅だけである（例: 13.8〜72.9倍）。

期待値計算には必ず **`odds_place_min_1m`（下限側）** を使った。

| 使う値 | 的中時の実測平均配当との関係 | 判断 |
|---|---|---|
| `min_1m`（採用） | 2.74倍 ← 実測 3.34倍 | **保守的。過小評価する側** |
| `max_1m` | 4.92倍 ← 実測 3.34倍 | 過大評価。使ってはならない |
| 中間値 | 3.83倍 ← 実測 3.34倍 | やや過大評価 |

min 側は実測より約18%低く見積もる。**この保守性は意図的で、
存在しない有利さを織り込まないためである。** min_1m と実測配当の相関は 0.94。

複勝ラベル `placed` は確定払戻 `payout_place > 0` で定義した。
これによりJRAの規定（7頭以下は2着まで、8頭以上は3着まで）が自動的に反映される。

## 2. 本題: 同じ馬を複勝で買うとどうなるか

**買う馬は1頭も変えない。** 単勝戦略（EV≥1.20・10〜150倍・ドリフト≤-0.05）が
選んだ3,039点の券種だけを複勝に替える。これを**戦略A**と呼ぶ。

| 指標 | 単勝（現行） | **複勝（戦略A）** |
|---|---|---|
| 賭け点数 | 3,039 | 3,039 |
| 的中 | 155点 | **630点** |
| **的中率** | 5.10% | **20.73%** |
| 平均配当（的中時） | 26.86倍 | 5.92倍 |
| **回収率** | **136.98%** | **122.67%** |
| **95%CI** | **[111.9, 164.9]** | **[112.1, 134.0]** |
| CI幅 | 53.0pt | **21.9pt** |

**点推定は14.3ポイント下がる。しかしCIの下側は 111.9% → 112.1% で変わらない。**
複勝が削ったのは上振れの裾（164.9% → 134.0%）だけである。

1レース3点上限を適用した運用ベース（3,010点）でも同じ構図になる。

| | 単勝 | 複勝 |
|---|---|---|
| 回収率（cap3・3,010点） | 134.85% | **122.55%** |
| 損益分岐ハンデ | 25.8% | **18.4%** |

> **NOTE: 損益分岐ハンデは単勝のほうが厚い**
> 全配当に何%のハンデを課すと100%に落ちるかという耐性は、
> 単勝25.8%に対し複勝18.4%。**手数料・約定ズレへの耐性は単勝が上**である。
> これは複勝が劣る数少ない軸なので正直に記しておく。

## 4. 配当集中度: 単勝版の最大の弱点が直る

単勝版 §6.3 は「上位20点（全体の0.7%）を失うと赤字に落ちる」ことを
正直に認めていた。ここが複勝で最も改善する。

![Place profit is not carried by a handful of payouts](img/anaba_place_concentration.png)

| 除外した上位配当 | 単勝 | **複勝** |
|---|---|---|
| なし | 137.0% | 122.7% |
| 上位1点 | 133.5% | 121.2% |
| 上位3点 | 127.1% | 119.2% |
| 上位5点 | 121.2% | 117.5% |
| 上位10点 | 108.8% | **114.1%** |
| **上位20点** | **90.0%（赤字）** | **108.5%** |
| **上位30点** | **76.2%（赤字）** | **103.7%** |

**k=7 付近で両者は逆転する。** そこから先は複勝のほうが常に上である。
**単勝は上位15点で赤字に落ちるが、複勝は上位39点まで耐える。**

これは「利益が一発に依存していない」という意味で、再現性の根拠として重い。
単勝の137%は155点の的中のうちごく一部が作っているが、
複勝の122.7%は630点の的中に分散している。

### 5.1 ラベルシャッフル検定（300回）

各レース内で `payout_place` をランダムに付け替えた（入着頭数は保存）。

| | 回収率 |
|---|---|

## 6. 資金管理: ここが複勝の本番

![Same horses, flat 1,000 yen](img/anaba_place_bankroll.png)

**この図が本レポートで最も重要である。**
緑（複勝）は最初の月から一度も大きく沈まずに右肩上がりに進むのに対し、
赤（単勝）は**最初の9ヶ月を水面下で這い、2025年4月にも大きく沈む**。
最終的な到達点は単勝が高いが、そこに至る道のりがまるで違う。

### 6.1 均等賭け（cap3・1点1,000円）

| 指標 | 単勝 | **複勝** |
|---|---|---|
| 総賭け金 | 3,010,000円 | 3,010,000円 |
| 損益 | **+1,049,100円** | +678,800円 |
| **最大ドローダウン** | **-186,100円** | **-55,600円** |
| **最長連続不的中** | **100点** | **23点** |

**最大DDは1/3.3、連続不的中は1/4.3になる。**
単勝版 §8 の「122点続けて外れる区間がある。12.2万円を一度も当たらずに
払い続ける覚悟が要る」という要求が、**複勝では23点・2.3万円で済む。**

### 6.2 fractional Kelly（複利・初期30万円）

| Kelly係数 | 単勝 最終資金 | 単勝 最大DD | 複勝 最終資金 | 複勝 最大DD |
|---|---|---|---|---|
| 0.05 | 65.7万円（×2.19） | -16.5% | 81.2万円（×2.71） | **-12.7%** |
| **0.10** | 117.4万円（×3.91） | -29.4% | **194.3万円（×6.48）** | **-23.7%** |
| 0.25 | 415.4万円（×13.85） | -57.6% | 1,825万円（×60.8） | -43.6% |
| 0.50 | 983.5万円（×32.8） | -81.3% | 8,763万円（×292） | -51.5% |
| 1.00 | 2,137万円（×71.2） | **-93.7%** | 2.18億円（×727） | -54.2% |

> **IMPORTANT: この表の複勝側を額面どおり受け取ってはならない**
> Kelly は**期待値が正の点しか賭けない**。保守側の複勝オッズ（min_1m）で
> 評価すると、**戦略Aの3,010点のうち期待値が正なのは1,264点（42.0%）だけ**である。
> つまり Kelly の複勝は**単勝と同じ馬を買っていない。** 残り1,746点を捨てている。
> **倍率を直接比較すると別物を比べることになる。**

その内訳を均等賭けで見ると、Kelly が賭ける側が実際に良い。

| 戦略Aの内訳 | 点数 | 複勝的中率 | 複勝回収率 | 95%CI |
|---|---|---|---|---|
| **複勝EV>1（Kellyが賭ける）** | 1,264 | 20.57% | **134.40%** | [117.5, 152.5] |
| 複勝EV≤1（Kellyが捨てる） | 1,746 | 20.85% | 113.97% | [100.1, 128.1] |

**捨てられる側も113.97%あり、100%を割っていない。**
Kelly の高倍率は「より良い部分集合に集中している」ことの結果であって、
複勝そのものが単勝の6倍優れているという意味ではない。

**均等賭けで券種だけを比べるなら §6.1 の数字（122.55% / DD -55,600円）が正しい。**

## 7. 発展: 複勝専用モデルで選び直す（戦略B）

ここまでは単勝モデルが選んだ馬を流用した。
**複勝確率 × 複勝オッズ**で期待値を取り直すと、さらに上がる。

```
[3'] 次の3条件を全て満たす馬を買う
      ・複勝EV = 複勝予測確率 × 1m複勝オッズ(min側) ≥ 1.15
      ・1m複勝オッズ(min側)が 2倍以上 60倍以下
      ・log(1m単勝オッズ / 5m単勝オッズ) ≤ -0.05   ← 単勝版と同じドリフト条件
```

| 戦略 | 点数 | 的中率 | 回収率 | 95%CI |
|---|---|---|---|---|
| 単勝（現行） | 3,039 | 5.10% | 136.98% | [111.9, **164.9**] |
| 複勝A（同じ馬） | 3,039 | 20.73% | 122.67% | [112.1, 134.0] |
| **複勝B（専用モデル）** | **1,135** | **20.26%** | **138.79%** | **[118.6, 160.5]** |

**戦略BのCI下側 118.6% は単勝の 111.9% を上回る。**
点推定でも単勝を上回り（138.79% vs 136.98%）、しかも分散は小さい。

### 7.1 しきい値感度

![Place-native ROI across the threshold range](img/anaba_place_sensitivity.png)

| EVしきい値 | 1.00 | 1.05 | 1.10 | **1.15** | 1.20 | 1.25 | 1.30 | 1.35 | 1.40 | 1.45 |
|---|---|---|---|---|---|---|---|---|---|---|

### 7.2 戦略Bの限界

> 本レポートは戦略Bを「有望な方向」として提示するに留め、
> **即時の運用推奨は戦略A（§2）とする。**

## 8. 結論: どちらを買うべきか

### 8.1 判断基準

| 状況 | 推奨 | 理由 |
|---|---|---|
| **資金30万円未満** | **複勝** | 連続不的中23点・DD5.6万円なら小資金で回せる |
| **数ヶ月で手応えが欲しい** | **複勝** | 単勝は最初の9ヶ月がマイナス圏。複勝は前半から121% |
| 資金が十分・分散に耐えられる | 単勝 | 点推定137%・上振れ165%は複勝では届かない |
| 手数料や約定ズレが大きい | 単勝 | 損益分岐ハンデが25.8%と厚い |
| **80倍超の馬** | **単勝のまま** | 複勝は108%まで落ちる（§5.2） |
| **15〜50倍の馬** | **複勝が有利** | 複勝121〜145%（§5.2） |

### 8.2 複勝で運用する場合に守るべきこと

1. **期待値は必ず複勝オッズの min 側で計算する。** max 側や中間値を使うと、
   締切前には確定していない有利さを織り込むことになる。
2. **Kelly係数は0.10まで。** 複勝でもフルKellyは54%のドローダウンを通過する。
3. **回収率は122.67%ではなく112.1%（信頼区間の下側）を期待値として計画する。**
4. **9頭以下のレースは避ける。** 複勝が2着までしか払わない7頭以下は特に悪い（45%）。
5. **G1は避ける。** 複勝でも60.7%で、単勝と同じく最悪である。
6. 単勝と同じく、**年次の回収率を追い続け、2年連続で100%を割ったら撤退**する。

### 8.3 一行で

> **単勝は「大きく勝つが、長く耐える」戦略。複勝は「そこそこ勝つが、ほとんど耐えない」戦略。**
> **期待値の下限で見れば両者は互角であり、複勝のほうが遥かに低リスクでそこに到達する。**

## 9. 限界

1. **検証はOOS 2年7ヶ月**（8,340レース）。単勝版と同じ期間・同じデータなので、
   **単勝版が持つ限界（§9 の1〜6）はすべてそのまま引き継いでいる。**
   特に「市場が学習すれば消える」「1m発注の執行リスク」「自分の賭けが
   価格を動かす影響は未検証」は券種を替えても解決しない。

2. **複勝オッズの約定ズレは未検証。** 本レポートは min 側で期待値を見積もり、
   確定払戻で決済しているので保守側に倒れているが、
   **締切までに複勝オッズがさらに下がる可能性そのものは測っていない。**
   単勝版 §7 に相当する執行可能性の検証を複勝で行っていない。

3. **損益分岐ハンデは単勝より薄い**（18.4% vs 25.8%）。
   手数料や約定ズレの耐性は単勝のほうが上である。

4. **戦略B（§7）のしきい値は事前固定ではない。** 新データでの追検証が要る。

5. **§5 のレース条件は購入ルールに入れていない。** 単勝版と同じ理由で、
   検証データを見て決めた条件だからである。

6. **複勝オッズ時系列は2023年以降しか使えない。** 単勝版 §1.3 と同じ制約で、
   `1m` スナップショットが実質的に更新されるのが2023年以降のためである。
